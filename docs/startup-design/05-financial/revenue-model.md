## Pricing strategy

| SKU | Price `[Assumption]` | Rationale |
|---|---|---|
| Snapshot (one-time list) | €3.99–7.99 (flagship ≤€9.99) | Travel guide bands; Mapstr users beg for one-time; PT discretionary |
| Creator/platform sub | ≤€2.99–3.99/mo or ≤€29.99/yr | Below Mapstr €59/yr; near Beli Elite memory |
| Sponsored placement | €150–500/mo per neighbourhood list `[Assumption]` | Below TheFork cover maths; test with 3 restaurants |
| Personal saves | **Free unlimited** | Avoid Mapstr backlash |

**Lead with:** Sponsored + Snapshot tests. **Do not lead with:** €5/mo consumer sub.
