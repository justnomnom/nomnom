## High Priority

### Add author identity to homepage testimonial
**File:** `src/sections/home/home-testimonial.js`

**What:** Add an avatar image, display name, and @handle below the testimonial quote. The component currently renders only the quote and a kicker heading — no person is identified.

**Why:** An anonymous testimonial on a "trust the person" platform is self-defeating. The brand promise is "picks from people you trust" — having an unattributed quote contradicts that message at the top of the funnel.

**Pros:** ~15 lines of markup. Immediate trust signal for homepage visitors.

**Cons:** Can't ship a placeholder — requires getting a real user's permission to be featured.

**Context:** `home-testimonial.js` renders the quote from i18n keys (`pages.home.testimonial.*`). The avatar can be sourced the same way as `HERO_CIRCLE_AVATARS` in `home-hero.js` (SVG or hosted image). The @handle should link to `paths.dashboard.userPublic(handle)`.

**Implementation sketch:**
```jsx
// Below the blockquote, add:
<Stack direction="row" alignItems="center" spacing={1.5} sx={{ mt: 3 }}>
  <Avatar src={TESTIMONIAL_AVATAR} sx={{ width: 44, height: 44 }} />
  <Box>
    <Typography variant="subtitle2" sx={{ fontWeight: 700 }}>{TESTIMONIAL_NAME}</Typography>
    <Typography variant="caption" sx={{ color: 'text.secondary' }}>@{TESTIMONIAL_HANDLE}</Typography>
  </Box>
</Stack>
```

**Depends on:** Permission from a real user to feature them on the homepage.
