# User Journey — NomNom Spearhead

**Phase:** 6 — Product  
**Date:** 26 July 2026  
**Primary path:** WhatsApp group decide (Tiago organiser → friends)  
**Secondary path:** Creator bio → `/u/handle` → save/share

---

## End-to-end map

| Stage | Actor | Touchpoint | Emotion | Job done? |
|---|---|---|---|---|
| 0. Trigger | Group | “Onde vamos sábado?” in WhatsApp | Mild stress | No |
| 1. Create | Organiser | Builds NomNom List (saves / creator picks / Roulette pool) | Hopeful | Partial |
| 2. Share | Organiser | Partilhar → public-link OG card | Relief if pretty | — |
| 3. Open | Friends | Auth-free list, no install | Curiosity / low friction | — |
| 4. Decide | Group | Vote / veto / Roulette | Fun → relief | **Yes** |
| 5. Go | Group | Maps / walk-in / book elsewhere | Hungry | Downstream |
| 6. Return | Organiser | Next week’s dinner → reopen NomNom | Habit? | Retention test |
| A. Creator path | Creator | Claims `/u/handle`, Stories link | Ownership | Supply |
| B. Lurker path | Visitor | Roleta or SEO long-tail | Playful | Acquisition |

---

## Aha moment
**When a friend who has never heard of NomNom opens the link, understands the shortlist in two seconds, and the group picks a place without another 40-message spiral.**

Not: first app install. Not: first follow. Not: first paid Snapshot.

---

## Drop-off risks & mitigations

| Risk | Where | Mitigation |
|---|---|---|
| Ugly/empty OG → nobody taps | Share | Remotion card quality |
| Login wall surprise | Open | Keep auth-free forever for view/vote |
| Empty list / empty profile | Open | Pre-seed; single-player import |
| “Another app?” suspicion | Open | Copy: no install required |
| Decide happens then never returns | Return | Make creating list #2 easier than #1; personal archive value |
| Creator ignores DM | Claim | Pre-build show-don’t-tell |
| #pub unmarked spoils trust | Decide | Forced disclosure UI |

---

## Emotion curve (target)
Stress (chat) → curiosity (OG) → clarity (list) → play (Roulette) → relief (chosen) → quiet trust (named sources).

---

## Flags

**Red:** If aha requires everyone to follow each other first, journey fails cold-start.  
**Yellow:** Tourist Snapshot journey is separate — don’t conflate metrics with local decide loop.
